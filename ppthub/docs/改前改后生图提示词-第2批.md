# PPT术语图鉴 ·「改前 vs 改后」生图提示词（第 2 批 × 12）

> 规则同第 1 批：
> - 每张图**文字 / 数据完全相同**，只改视觉处理 → 对比才成立。
> - 比例统一 **16:9**。
> - 提示词**全中文**，当成「一张真实 PowerPoint 幻灯片截图」来生成。
> - **每个代码块都是独立的、可直接一键复制的完整提示词**——文案 / 画面要求 / 负向提示词三段都在同一块里。
> - 文案风格口语化、好懂易懂。
