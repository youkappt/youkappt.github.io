# PPT术语图鉴 ·「改前 vs 改后」生图提示词（第 3 批 × 68）

> 规则（与第 1、2 批完全一致）：
> - 每张图**文字 / 数据完全相同**，只改视觉处理 → 对比才成立（这条必须死守）。
> - 比例统一 **16:9**。
> - 提示词**全中文**，当成「一张PPT页面」来生成。
> - **每个代码块都是独立的、可直接一键复制的完整提示词**——文案 / 画面要求 / 负向提示词三段都在同一块里。
> - 文案风格口语化、好懂易懂。
>
> 说明：本批 68 个术语来自「设计原则 / 字体与配色 / 排版与布局 / 图形与图示 / 母版与版式」中尚未写过的部分。其中少数「软件操作类」术语（如字体版权、Excel 链接、编辑顶点等）的对比，体现在「不遵循该规范 / 不用该功能」的幻灯片 vs「遵循 / 用了」的幻灯片——文案仍是同一页、只改效果。
