# PPT 术语图鉴（PPThub）· 设计文档

> 暗色玻璃风的「PPT 术语图鉴」子站｜参照 AuthKit 设计系统（午夜深色 + 磨砂玻璃 + 单一紫罗兰 `#663af3` 强调色），灵感源自 vibe-hub 信息架构。
> 现为「优卡导航」(youka-nav) 的子页面，代码位于 `youka-nav/ppthub/`。

## 1. 定位与技术架构
- **PPT 术语图鉴（副品牌 PPThub）** = 暗色玻璃拟态风格的 PPT 术语图鉴：按分类组织大量 PPT 术语，每个术语用大白话解释「是什么、什么时候用」，并配**专属定制图示/可交互演示**。
- 品牌：主名称「PPT 术语图鉴」，PPThub 作为副品牌保留（仅出现在 `<title>` 与页脚「PPT 术语图鉴 · PPThub」）。
- 技术：**纯静态单页，零构建**。
  - `index.html` — 骨架（顶栏照搬优卡导航：优卡头像 logo + 「PPT 术语图鉴」+ 玻璃搜索框）
  - `styles.css` — AuthKit 设计 token 与全部组件样式
  - `data.js` — 词条数据数组（加词只改这一个文件 + 在 demos.js 补演示）
  - `demos.js` — 每个词条专属演示函数，注册到 `DEMOS` 映射（文字与行为分离）
  - `terms-extra.js` — 词条补充字段（误区 / 快捷键 / 自检清单 / 改前改后 / 记忆口诀 / 进阶组合技 / 词源小注）
  - `beforeafter.js` — 改前 vs 改后 静态视觉对比图
  - `app.js` — 渲染分类、实时搜索、卡片网格、玻璃详情弹窗（含左右上/下术语导航）、关联概念跳转、演示挂载
  - `logo.png` — 优卡头像（与优卡导航同款）
- 本地预览：`python3 -m http.server`（youka-nav 根目录）后访问 `/ppthub/`；也可在 `ppthub/` 单独起服务。
- 部署：作为 youka-nav 子页面随主站发布；未单独部署（按 7/24 约定需显式授权）。

## 3. 页面结构（单页）
1. **顶栏**：优卡头像 logo + 「PPT 术语图鉴」+ 玻璃搜索框（照搬优卡导航，搜索框规格与优卡导航一致）
2. **Hero**：eyebrow「「优卡说PPT 出品」」→ 渐变大标题「PPT 术语图鉴」→ 两行副文案（用大白话… / 每个术语都配专属图示与可交互演示）
3. **分类导航**：左侧 sticky 玻璃分类面板（全部 + 8 分类），点击筛选，与搜索叠加
4. **词条网格**：响应式玻璃卡片（中文词 + 英文别名 + 一句话预览 + 难度/分类 badge），hover 上浮
5. **词条详情弹窗（玻璃 Modal）**：大标题 + 别名 + 难度 → 速记 → 是什么 → 常见场景 → 动手试试(演示) → 常见误区 → 快捷键/调出 → 自检清单 → 改前vs改后 → 记忆口诀 → 进阶组合技 → 词源小注 → 关联概念（可跳转）；弹窗左右两侧胶囊按钮切换上/下术语
6. **页脚**：PPT 术语图鉴 · PPThub + 微信公众号「优卡说PPT」

## 4. 数据模型（data.js 每词一条）
```
{ id, name, alias, category, level, summary, detail, scenario, related[], demo }
```
- `demo` 指向 `demos.js` 中同名函数；无则留空（纯文字）。
- `level` 仅两档：「入门」/「进阶」（曾有的「高手」档已统一并入「进阶」）。

## 5. 演示架构（每词定制）
- `demos.js` 内 `const DEMOS = { master(){...}, alignment(){...}, ... }`，每个 term 的 `demo` 字段映射到自己的渲染函数，返回定制 DOM（HTML+CSS+JS 现写）。
- 文字（`data.js`）与行为（`demos.js`）分离，扩展只动数据 + 加一个函数。
- 带定时器的演示统一注册到 `window.__demoTimers`，弹窗关闭时 `cleanupDemo()` 清理，无后台空跑。

## 6. 词条分类（8 类，113 条）
- **软件功能**：母版、版式、占位符、动画窗格、参考线、布尔运算（联合/相交/减除等）、取色器、SmartArt、节(Section)、幻灯片缩放定位
- **设计原则**：对齐、亲密性、对比、重复、视觉层级、留白、焦点引导、栅格系统
- **字体与配色**：衬线/无衬线、字号阶梯、字重、字间距、邻近色、对比色、主辅点三色、渐变
- **动画与切换**：进入/退出/强调、平滑vs突然、缓动曲线、触发方式、切换效果、时间轴
- **排版与布局**：黄金比例、三分法、F型阅读、中心对称、页边距、栏宽
- **效率与技巧**：格式刷、快捷键、对齐分布、取色复用、矢量vs位图、图片压缩
- **图形与图示**：图标风格统一、图表美化、SmartArt转形状
- **输出与放映**：16:9宽屏、导出PDF、演讲者视图、超链接跳转、自动播放

## 7. 交互逻辑
- 实时搜索：过滤 `name/alias/summary/detail`，输入框空时不显示结果计数
- 分类 + 搜索叠加；空结果玻璃占位
- 弹窗内「关联概念」点击 → 直接跳到对应词条
- 弹窗左右胶囊按钮（含术语名）→ 上/下术语切换（`←`/`→` 键同效，`Esc` 关闭）
- 每词演示区随弹窗渲染，独立作用域互不干扰
