## 修复 modal-nav 真正视口固定（backdrop-filter 包含块陷阱）
- **现象**：用户反馈弹窗左右导航按钮应固定浏览器窗口，但改 `position: fixed` 后仍随弹窗内容滚动而滑走。
- **根因**：`.modal-overlay` 的 `backdrop-filter: blur(8px)` 会创建包含块，使子元素 `.modal-nav` 的 `position: fixed` 相对于 overlay 盒子而非视口。overlay 有 `overflow-y: auto`，内部滚动时按钮跟着跑。
- **修复**：将 `background` + `backdrop-filter` 从 `.modal-overlay` 移到 `.modal-overlay::before` 伪元素上（`position: fixed; inset:0; z-index:-1`）。overlay 本身不再有 backdrop-filter → 不再创建包含块 → `.modal-nav` 真正钉在视口两侧。
- **改动文件**：ppthub/styles.css（L601-630 + L1030 reskin）、ppt-tips/styles.css（L603-632 + L1139 reskin）。两页同步。
