## 性能诊断：工具区加载慢
- 现象：用户反馈首页「AI×设计工具箱」区域空白后缓慢出现（Hero 静态卡正常，工具区依赖 `fetch('./tools.md')`）。
- 根因定位（curl 实测）：
  1. **`fetch` 用了 `cache:'no-store'`** → 每次强制绕过 HTTP 缓存重新拉 `tools.md` + `manifest.json`，热状态也不复用。
  2. **`github.io/youka-nav/` 被 301 重定向到自定义域名 `youkappt.com`**（每次访问多一次跨域往返）；且 `youkappt.com/youka-nav/` 直接 404（"Page not found"）→ CNAME 配成 apex 域名但站点为项目站点，路径错位，**自定义域名配置有误**是更大的慢源/隐患。
  3. 图标本身已本地缓存（`logos/manifest.json` 36 项 + `loading=lazy`），非瓶颈；48 卡片同步渲染仅数十毫秒。
- 已做前端修复（`index.html`，本地未部署）：
  - 两处 `fetch` 去掉 `cache:'no-store'`（回到浏览器默认协商缓存，热状态秒开、部署更新仍可 304 见新内容）。
  - favicon `<img>` 加 `decoding="async"`。
  - 新增 `#loading` 加载态提示（`load()` 开始显示「⏳ 正在加载工具列表…」、render 后隐藏、catch 也隐藏），避免用户以为坏了。
- 待办（需用户决策 + 部署授权，未擅自改）：**301/自定义域名问题**。最快解法=放弃自定义域名（删 CNAME + GitHub 设置取消自定义域名），github.io 直连无 301；或把仓库改 `youkappt/youkappt.github.io` 让 `youkappt.com/` 直接承载（项目站点不支持子路径自定义域名）。
