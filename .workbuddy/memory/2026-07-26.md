## ⚠️ CSS 注释里写 `*/` 会静默吞掉后续规则（今天踩过）
- 现象：用户给 authkit 截图让我直接抄 .back-link 样式，我把新规则追加到 styles.css 末尾 `/* PPT 技巧页 — 追加样式（复用上方 token 与 .ba-*/.demo-*/.related-*） */` ——注释里 `*/` 让 CSS 解析器提前结束注释，剩余注释被当 CSS 解析失败 → 浏览器错误恢复跳过 `.back-link { }` 基础块（只剩 `:hover/:active` 子规则），按钮静态样式完全没生效（颜色回到浏览器默认链接蓝）。
- 教训：CSS 注释里**绝不能含 `*/`**。需要提及时用「、」或半角斜杠代替，例如 `.ba-*、.demo-*、.related-*`。
- 排查手段：用 css-tree (`require('css-tree')` 工作区已装，`$NODE -e "const t=require('css-tree');t.parse(css,{onParseError:e=>console.log(e.line,e.message)})"`) 一行命令就能定位 line+N 错位；比肉眼比对括号高效得多。
- 修复：把那条注释里的 `*/` 全改成 `、`，CSS 0 parse errors，按钮 7 项 computed style 全部精确命中 authkit 截图。

## 移动端「向下滚动被回拽」bug 修复
- 现象：移动端（≤920px）向下滑，页面被反复往回拽/跳动，滚不下去。Playwright(iPhone12) 复现：滚 40 步出现 14 次回拽（单次最高 -651px），最终卡在 scrollY≈1537。
- 根因：`setSideActive()`（index.html ~859 行）用 `sel.scrollIntoView({block:'nearest',inline:'center'})` 居中当前分类项。移动端侧栏折叠成 `position:static` 的横向滚动条、处在页面顶部；scrollspy 滚动时反复触发，`block:'nearest'` 为把导航条带回视口而**连带纵向滚动 window** → 页面被拽回导航条所在的 ~1357px 位置。
- 修复：改为**只滚导航容器自身**（`nav.scrollBy`，绝不触碰 window）。`nav.scrollWidth>clientWidth`（移动端横向）→ 横向 scrollBy 居中；否则 `scrollHeight>clientHeight`（桌面竖直侧栏）→ 纵向 scrollBy 居中。scrollBy 只作用于元素自身，不可能滚动页面。
- 验证：修复后移动端滚 40 步 scrollY=7200 全程回拽 0 次；桌面端滚 30 步 scrollY=9000 回拽 0 次且侧栏 active 仍随滚动更新 22 个分类。verify_before_deploy 9/9 PASS。
- 教训：SPA scrollspy 里给"当前项"做居中，禁用 `scrollIntoView`（会向上冒泡滚动所有祖先含 window），改用 `container.scrollBy/scrollTo` 只滚容器。
