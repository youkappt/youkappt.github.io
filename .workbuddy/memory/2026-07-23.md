## 瀑布流改造成「最短列优先 + 列错位」（错落有致）
- 原 CSS `columns` 是竖向填充（先满第1列再第2列），列顶齐平、不够错落。
- 改为 JS 瀑布流：`.gallery` 变 flex 行，内含 N 个 `.masonry-col` 列容器；每张卡放入「当前估计高度最小」的列（estHeight 伪随机 260~580px 做均衡分配），列间高度均衡且自然错落。
- 每列顶部加 `translateY` 视觉错位（4列=[0,54,26,80] / 3列=[0,42,21] / 2列=[0,30]），形成对角线错落；错位仅装饰不参与高度计算，避免最短列逻辑被偏移干扰。
- 懒加载保留（setupLazy + IntersectionObserver）；resize 时列数变化则重建（200ms 防抖）。响应断点 4/3/2 列由 JS getColCount 按宽度决定，CSS 只调间距。
